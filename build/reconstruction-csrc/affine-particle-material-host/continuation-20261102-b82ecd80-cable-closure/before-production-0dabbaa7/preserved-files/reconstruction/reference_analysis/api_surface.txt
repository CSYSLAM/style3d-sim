MODULE DOC: 
Native bindings for Synreal Solver.

Array fields are represented by non-owning Span objects that refer to CUDA
device memory. The caller is responsible for keeping every referenced device
allocation alive for as long as native code may access it.

### Config  [pybind11_type]

Runtime configuration for a Synreal solver.

Changes made through ``solver.config`` affect subsequent direct step calls.
Previously captured CUDA graphs must be rebuilt after a configuration change.

  .__init__: __init__(self: _core.Config) -> None

Create the default solver configuration.

  .affine_body_block_preconditioner: Use a full affine-body block inverse as the PCG preconditioner.
  .affine_body_contact_block_preconditioner: Include hard-contact cross terms in affine-body PCG blocks without changing the contact operator.
  .affine_body_rigidity_model: Rigidity law used for affine bodies: co-rotated, original ABD orthogonality, six springs, or SO(3) AL.
  .affine_body_rigidity_primal_iterations: Primal Newton iterations performed with a fixed affine-body SO(3) AL state before each update.
  .air_density: Ambient air density in kg/m^3; zero disables aerodynamic drag.
  .cable_angular_beta: Cable bend/twist penalty ramp per nonlinear iteration; zero uses authored stiffness.
  .cable_angular_k_start: Initial cable bend/twist penalty when the angular penalty ramp is enabled.
  .cable_linear_beta: Cable stretch/shear penalty ramp per nonlinear iteration; zero uses authored stiffness.
  .cable_linear_k_start: Initial cable stretch/shear penalty when the linear penalty ramp is enabled.
  .cable_penalty_gamma: Cable penalty decay per step, clamped to its initial floor and authored cap.
  .constraint_alpha: Shared dimensionless mass-normalized penalty for affine rigidity, generated joint constraints and hard distance constraints. Zero disables all three.
  .enable_collision_hessian_non_diagonal: Include coupled contact tangents for rigid, particle-shape, and all self-collision contacts, False keeps their diagonal approximation; full-surface and angular-friction tangents remain coupled.
  .enable_self_collision: Whether deformable self-collision is enabled.
  .fluid_max_step_ratio: Bound fluid Newton increments relative to kernel radius; zero disables.
  .fluid_relaxation: Global Newton step scale in fluid scenes, in (0, 1].
  .inertia_mode: ABD inertia construction and velocity recovery mode; NONE selects the free-particle path.
  .joint_constraint_mode: Joint-constraint enforcement method; PENALTY preserves the legacy behavior.
  .joint_constraint_primal_iterations: Primal Newton iterations performed with a fixed augmented-Lagrangian dual before each multiplier update.
  .linear_iterations: PCG iterations per nonlinear iteration.
  .nonlinear_iterations: Nonlinear iterations per step.
  .nonlinear_solver: Implicit-Euler nonlinear method: NEWTON or the legacy PD_NEWTON method.
  .rigid_contact_alpha: Hard-contact C0 stabilization in [0, 1].
  .rigid_contact_beta: Hard-contact penalty ramp per iteration.
  .rigid_contact_friction_epsilon: VBD-style rigid Coulomb smoothing speed [m/s]; zero preserves the native secant law.
  .rigid_contact_gamma: Hard-contact history decay in [0, 1].
  .rigid_contact_hard: Use augmented-Lagrangian normal contact and displacement-based Coulomb friction.
  .rigid_contact_history: Warm-start hard-contact multipliers through Contact.match_index.
  .rigid_contact_k_start: Initial hard-contact penalty when the penalty ramp is enabled.
  .rigid_contact_sliding_tangent: Differentiate the hard-contact Coulomb disk at fixed normal load; False keeps the legacy tangent.
  .rolling_friction_velocity_epsilon: Positive contact angular-speed regularization for rolling and torsional friction [rad/s].
  .self_collision_edge_edge_stiffness: Dimensionless stiffness scale for edge-edge self-collision penalties.
  .self_collision_edge_face_stiffness: Dimensionless stiffness scale for edge-face untangling penalties.
  .self_collision_particle_particle_stiffness: Dimensionless stiffness scale for free-particle pair collision penalties.
  .self_collision_radius: Radius used to thicken deformable collision primitives.
  .self_collision_vertex_face_stiffness: Dimensionless stiffness scale for vertex-face self-collision penalties.
  .wind_velocity: Ambient air velocity as a world-coordinate (x, y, z) tuple in m/s.

### Span  [pybind11_type]

A non-owning view of a contiguous CUDA device-memory range.

Span stores an opaque device address and an element count. It does not allocate,
free, or dereference the referenced memory. Construction and field assignment
reject a null address paired with a nonzero element count.
